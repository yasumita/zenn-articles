# Tips
## キーボードショートカット
- [チートシート](https://code.visualstudio.com/docs/getstarted/tips-and-tricks)
- 前のファイルへ戻る： `Alt + ←`
- 次のファイルへ進む： `Alt + →`
- 定義されている場所に飛ぶ： シンボルにカーソルを合わせて `F12`
- ファイル内のシンボル検索：`Ctrl + Shift + o`
## 起動
ファイルの差分表示
```bash
code -d a.py b.py
```
## マルチカーソル機能
- カーソル位置にある単語と同じ単語を一括して選択 `Ctrl + Shift + L`
- カーソル位置にある単語と同じ単語を1つずつ選択範囲に追加 `Ctrl + D`
