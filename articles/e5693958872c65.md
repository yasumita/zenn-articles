# 準備

環境はWindows 11かUbuntu 24.04を想定しているが、Mac OSでもおそらく可能。
ブラウザはChrome（Chromeの拡張機能が使える他のブラウザでもおそらく可能）。

以下をインストール。使い方については省略。

- Obsidian: メモアプリ
  - インストール: https://help.obsidian.md/install
  - 空のVaultを作っておく。クラウド上ではなくローカルに作る。: https://help.obsidian.md/vault
- Zotero: 文献管理ソフト
  - ダウンロード: https://www.zotero.org/download
  - Zotero Connector (Chromeの拡張機能)も追加する
  - さらにプラグインを2つ追加する
    - Better BibTeX for Zotero: 引用キーを自動で変更する。
      - インストール: https://retorque.re/zotero-better-bibtex/installation/index.html
    - Zotero Attanger: PDFの保存先とファイル名を指定できる。
      - [Zotfile](https://zotfile.com)が既にメンテナンスされていないためこれで代替。
      - インストールはBetter BibTeXの場合と同様: https://github.com/MuiseDestiny/zotero-attanger

## ZoteroのCollectionとTagについて

CollectionとTagはともに、1つのアイテムに複数つけることができる。つけ方は好みによるが、自分の場合は以下。
- Collection: 分野→トピック(→あればサブトピック)というように細分化したものをつける。
  - 例: `Machine Learning`→`Transformer`→`Analysis`のように階層化する。
- Tag: 論文をZoteroに追加する際にトピックをつける。さらに、読んだ論文には`Read`というタグを、特に読むべき論文には`ToRead`をつける。
  - Tagは右クリックすると色を割り当てられることができ、さらに表示が固定される（自分は`Read`と`ToRead`に色を割り当てている）。

## 設定
### General
- Item Pane Header (好みで): `Title, Creator, Year`
- Automatically take snapshots when creating items from web pages: `off`
  - `on`にすると、文献を保存する時にそのページのHTMLファイルを添付ファイルとして保存する。
- File Renaming
  - Customize Filename Format...: `{{ citationKey }}`
    - ここでは引用キーをファイル名とする。変更可。
- Automatically tag items with keywords and subhect headings: `off`
  - `on`にすると、保存した文献が持っているキーワード情報を自動的にタグとして保存する

### Sync
最初にログインする。

- Sync automatically: `on`
- Sync full-text content: `on`
- Sync attachment files in My Library using ...: `off`
  - PDF等のファイルの同期はObsidianでは行わない
- Sync attachment files in group libraries using Zotero storage: `off`
  - 同上

### Attanger
- Source Path, Destination PathをPDFを保存するフォルダに設定
- Subfolderを`{{citationKey}}`
