# [What Do Language Models Learn and When? The Implicit Curriculum Hypothesis](https://openreview.net/forum?id=wjTjjHstuY) (COLM 2026)
Authors: Emmy Liu, Kaiser Sun, Millicent Li, Isabelle Lee, Lindia Tjuatja, Jen-tse Huang, Graham Neubig

- LLMの事前学習中に獲得されるスキルは安定した構成的な順序で獲得されるというImplicit Curriculum Hypothesis を提案し、それを検証した![](https://static.zenn.studio/user-upload/64d9d6b7497a-20261102.png)
	- 構成的な能力が、その構成要素となる能力よりも後に創発する傾向にある
	- 能力の出現順序は様々なモデルの間で一貫している

- 背景
    - LLMは計算量・パラメータ・学習データをスケールすることで性能が向上することが知られている（スケーリング則）が、どのような能力をどの時点で習得するかは分からない
        - 交差エントロピー損失: 個々の能力が急に獲得される時点があっても滑らかに減少する
        - 下流タスクのベンチマーク: 前提となる能力が多くあり、性能が伸びないときにどれが欠けているのか分かりにくい
            - 例: GSM8kの場合、数字の処理能力・多段推論・NLUなど
    - 先行研究では、単純なパターン→より複雑なパターンの順で学習されることが示されている
        - 量子化仮説: スケーリング則における滑らかな損失の曲線が、量子（離散的な能力）を、合計の損失を減らすように最適化された順番で学習していることによって生じるという仮説
        - 単純性バイアス：勾配降下法で学習したニューラルネットワークは先に単純な関数から学習する
    - 実験的な先行研究
        - 知識がカテゴリによって異なる速度で習得されること（例えば、構文や文法などのような統語的な知識が速く、事実についての知識はゆっくりというように）
        - スキルの依存関係のグラフを元にして、シンプルなタスクを先に、それらを組み合わせる必要があるようなタスクは後にというようにカリキュラムを設計して、LLMを事後学習すると、より少ないデータで学習できる
    - ただし、大規模な事前学習において、能力の獲得順序が能力間の依存関係を反映しているか、それが内部表現から読み取れるかは未検証だった。
- Implicit Curriculum Hypothesis: 事前学習において、能力は安定した構成的順序で出現し、これはモデル間で一貫している
    - H1 (Compositional ordering) は、あるタスクはそれに依存するように構成された別のタスクよりも遅く獲得されることはない、という構成順序の仮説（例えば、「翻訳する」→「翻訳したうえで全部大文字にする」）
    - H2 (Cross-model stability) は、（1つのモデルだけでなく）いろいろなモデルに対してタスクの獲得順序をならべたときに、その順番が一貫しているという、モデル間の安定性についての仮説
    - H3 (Representational alignment) は、（モデル内での）表現が似ているタスクについては学習の軌跡（獲得の過程）も似ているだろうという、表現の対応についての仮説
- 対象モデル
    - OLMo-2（1B/7B/13B）、OLMo-3（7B）、LLM360 の Amber（7B、自然言語中心のデータ）と CrystalCoder（7B、コード中心のデータ）、Pythia（410M/1.4B/2.8B/12B）
    - 学習の最初の最大 1T トークンから、各モデル約 20 チェックポイントを使う。
- タスク：![](https://static.zenn.studio/user-upload/b9571ea2cf97-20261102.png)
    - 単純タスク（53 個）
        - 文字列操作：copying、大文字化、先頭文字の抽出など
        - 形態変化：単数→複数、現在形→動名詞
        - 翻訳：英⇔仏、英⇔西
        - 世界知識：国→首都、国→通貨
        - その他：算術、論理、読解・照応解析、心理測定の認知テスト由来の課題
    - 複合タスク（76 個）：要素操作を順に連結したもので、前提タスクが構成上正確に分かる。
        - gerund upper：write → WRITING
        - translate eng fr upper reverse：hello → RUOJNOB
    - 5-shot の in-context learning（ICL）で提示し、完全一致で評価
- 出現の定義
    - 曲線が緩やかか急かを問わず、しきい値を初めて超えた点を出現とする。
        - 絶対しきい値：正解率。主に 0.8 を使う。
        - 相対しきい値：そのモデル・タスクでの最高性能の $\alpha$ 倍。
    - 最後まで超えないタスクは、最後尾で同順位として扱う。
- 内部表現（function vector, FV）
    - ICL プロンプトの最後のトークン位置（回答を生成し始める位置）の活性を、モデルが正解したプロンプトだけで平均する。
    - 抽出方法は次の 2 種類で、モデルごとに選ぶ。
        - 層 $\ell$ のブロック出力：$v^\ell_\tau = \frac{1}{|D^+_\tau|}\sum_{x_i \in D^+_\tau} h_{\ell, t_{\text{last}}}(x_i)$
        - causal indirect effect で選んだアテンションヘッド群（同一層から選ぶ）の出力の平均
    - 類似度はcosine類似度
- 検証方法
    - H1：前提タスクが合成タスクより後に出現した件数（違反率）を数える。
    - H2：モデル対ごとに、全タスクの出現順で Spearman 相関を計算する。
    - H3：合成タスク $c$ を 1 つ除外する leave-one-out で、残りのタスク集合 $S$ からFVが近いタスクの学習曲線で $c$ の学習曲線を予測する。
        - 単位正規化した FV 間の RBF カーネル $K(v_i,v_j)=\exp(-|v_i-v_j|^2/2\sigma_k^2)$ を使い、各ステップ $t$ でカーネルリッジ回帰を行う：$$\alpha_t=(K_S+\lambda I)^{-1}y_t,\quad \hat a_c(t)=k_c^\top \alpha_t$$
            - $y_t$ は $S$ の各タスクの時刻 $t$ での正解率、$k_c$ は $c$ と $S$ の各タスクとのカーネル値
        - 評価指標は、Pearson $r^2$（曲線の形の一致）と MAE（値のずれ）。
        - $S$ を単純タスクだけに制限した場合とも比較する。予測が悪化すれば、合成タスク同士には単純タスクだけでは表せない共通の構造 (Composition bottleneck)がある、と解釈する。
- 結果（H1, H2）
    - 創発したタイミングをタスクごとにヒートマップで図示![](https://static.zenn.studio/user-upload/bdc088cfb70a-20261102.png)
        - おおまかな出現順は次のとおり。
            1. copying と単純な照応解析
            2. 大文字化・小文字化などの単純なタスク
            3. 形態変化
            4. 翻訳など知識を要するタスク
            5. 難しいタスクや合成タスク
    - H1 の結果：統計的な傾向として成立
        - 76 件中 54 件で、合成タスクは前提より早く現れなかった。
        - 前提の片方より早かった例が 19 件、両方より早かった例が 3 件（3 件とも first letter が関係）。
    - 順位のばらつき（モデル間の標準偏差）![](https://static.zenn.studio/user-upload/719dfdf38516-20261102.png)
        - 早く現れるタスクで 2.8–3.2
        - 難しい翻訳や複合的なタスクで 18.4–21.7（最後まで出現しなかったタスクを同順位で扱ったため？）
    - H2 の結果：能力の獲得はモデル間で一貫している![](https://static.zenn.studio/user-upload/fa0577357dfe-20261102.png)
        - すべてのモデル対で $\rho$ が .64–.93であり統計的優位。系列をまたいでも高い
    - 相対しきい値では順序の一貫性の結果が変わる![](https://static.zenn.studio/user-upload/586841894b05-20261102.png)
        - 相関の平均は .300–.479 に下がる（弱いモデルが能力を獲得しないまま相対しきい値に早く達しうるため？）
- 結果（H3）![](https://static.zenn.studio/user-upload/f3004cc53581-20261102.png)
    - 全タスクを使った場合
        - $R^2$ は .676-.838、MAE は .068–.195で精度が良い
    - 単純タスクだけに制限した場合→単純タスクだけでは複合タスクの予測は不十分
        - MAE は全モデルで悪化した
    - OLMo2-7B の個別例![](https://static.zenn.studio/user-upload/73b730c8bc01-20261102.png)
        - translate fr eng upper（$R^2$=.985、MAE=.017）は、出現時期と立ち上がりをよく追えている。
        - translate eng fr upper（$R^2$=.51）では、予測が弱い。
- 限界・今後の課題
    - 結論の範囲は、英語の統制されたタスク群と 5-shot ICL に限られる。
    - チェックポイントを公開しているモデルが少ない。
    - 結果は出現しきい値の定義に依存する。
    - 因果的な依存関係や、自由形式のタスクへの一般化は示していない。
