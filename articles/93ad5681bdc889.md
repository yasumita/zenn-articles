# Windowsのちょっとしたコマンド
## ファイルの種類 (例: pdf) を限定してフォルダ内のファイルのサイズの合計を調べる

```PowerShell
Get-ChildItem -Recurse -Filter *.pdf | Measure-Object -Property Length -Sum | Select-Object @{Name="Total_MB"; Expression={[math]::round($_.Sum / 1MB, 2)}}
```

### フォルダの種類別一覧

```PowerShell
Get-ChildItem -Recurse -File | Group-Object Extension | Select-Object Name, @{Name="Count"; Expression={$_.Count}}, @{Name="Total_MB"; Expression={[math]::round(($_.Group | Measure-Object -Property Length -Sum).Sum / 1MB, 2)}} | Sort-Object Total_MB -Descending
```

## ファイルの種類 (例: md) を限定してフォルダ内のファイルのサイズを一覧

```PowerShell
Get-ChildItem -Recurse -Filter *.md | Select-Object FullName, @{Name="Size(KB)";Expression={[math]::round($_.Length / 1KB, 2)}} | Out-GridView
```

## フォルダ内にあるすべてのファイルの種類の一覧を調べる

```PowerShell
Get-ChildItem -File -Recurse | Group-Object Extension | Select-Object Name, Count
```
