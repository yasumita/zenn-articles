# [Evaluating Evaluation Metrics: A Framework for Analyzing NLG Evaluation Metrics using Measurement Theory](https://aclanthology.org/2023.emnlp-main.676/) (EMNLP 2023)
Authors: Ziang Xiao, Susu Zhang, Vivian Lai, Q. Vera Liao

* 教育・心理測定の測定理論を NLG の評価指標の評価に適用して指標の信頼性と妥当性を評価するフレームワーク METRICEVAL を提案。要約タスクの 16 種類の指標に適用し、LLM ベースの指標の信頼性の低さと、人手の評価における Coherence と Relevance の混同を検出した。
* 背景・既存手法の問題点
	* NLG 指標の良さは主に人手評価との相関で検証されてきた
	* しかし相関を見るだけでは限界があり、人手評価にも妥当性・標準化・一貫性・再現性に課題がある
* 問題設定
	* 評価対象は評価指標そのもの
	* ベンチマーク（例：CNN/Daily Mail）を固定したうえで、$N$ 個のモデルが行った出力に対して、各評価指標（ROUGE、BertScore、SUPERT、人間による評価など）の評価結果が信頼性・妥当性をどの程度持つかを調べる
* 提案フレームワーク：測定理論における2つの概念（信頼性・妥当性）を用いて測定誤差を分けて評価・比較する![](https://static.zenn.studio/user-upload/9085be833115-20260902.png)
	* **信頼性**: ランダム誤差（アルゴリズムの非決定性・評価者・問題ごとに変動し、繰り返せば平均 $0$ に収束する誤差）
		* 評価指標によるスコア $X$ は、モデルの真のスコア $T$ と、 $T$ と独立で平均 $0$・分散 $\sigma_E^2$ の測定誤差 $E$ の和（$X = T + E$）で表される
		* 目的は、測定誤差の大きさ（標準測定誤差 $\sigma_E$）とその発生源を推定すること
		* 信頼性係数$\rho_{XT}^2$を以下のように定義し、$T$ か $E$ を経験的に測定することで推定する（高いほど良い）$$\rho_{XT}^2 = \frac{\sigma_T^2}{\sigma_X^2} = 1 - \frac{\sigma_E^2}{\sigma_X^2} \in [0,1]$$
		* 具体的に推定する方法は2つ
			* 安定性 (**Stability**)：同一の出力を再度評価したときにスコアがどの程度変動するか。同じ出力に対し 2 回スコアを計算し、$N$ 個のモデルについて 2 つのスコアセットの相関係数 $\rho_{X_1 X_2}$（再テスト信頼性係数）をとる
				* $X_1 = T_1 + E_1,\ X_2 = T_1 + E_2$ かつ $\sigma_{E_1} = \sigma_{E_2}$ であるから、 $\rho_{X_1 X_2} = \rho_{X_1 T_1}^2$ となる
				* 決定的な指標（ROUGEなど）では $\sigma_E = 0$ だが、確率的な指標（G-Eval など）では不明
				* この値が低いと、評価の試行ごとに変動が大きいことを意味する（→複数回実行して平均を取れば解消される）
			* 一貫性 (**Consistency**)：ベンチマーク内のデータ点間でのスコアがどの程度変動するか。$J$ 個のテストデータがあるとし、$j$ 番目のデータ点でのスコアを $Y_j$、全体スコアを $X = \sum_{j=1}^J Y_j$ としたときの、Cronbach の $\alpha$ 係数が $X$ の信頼性の下界となる:$$\rho_{XT}^2 \ge \alpha = \frac{J}{J-1}\left[\frac{\sigma_X^2 - \sum_{j=1}^J \sigma_{Y_j}^2}{\sigma_X^2}\right]$$
				* この値が低いと、データセットから得る事例の選び方に敏感であることを意味する（→データ数を大きくすれば解消される）
	* **妥当性**: 系統的な測定誤差（持続的に表れる偏り）
		* テストそのものの妥当性ではなく、スコアから引き出される推論の妥当性を検証対象とする
		* 具体的に推定する方法は2つ
			* 検証済みの基準（例：専門家の評価）があるとき→ 併存的妥当性(**Concurrent Validity**)：検証済みの基準を外部基準 $Y$ とし、対象指標 $X$ との Pearson 相関 $\rho_{XY}$ （(criterion-related) validity coefficient）で評価する
				* ただし、$\rho_{XY}$ は母集団レベルでの$X$と$Y$の信頼性の積の平方根が上界となるので、信頼性の低い指標は基準予測力も低くなることに注意
			* 外部基準がない場合→ 構成概念妥当性 (**Construct Validity**): テストにおける観察可能な行動（テストスコアなど）が意図された構成概念（言語能力など）をどの程度適切に反映しているかを示す尺度
				* モデルの性能や出力品質の特定の側面を評価する目的で明示的に構築された評価指標（要約に特化した人手評価や一貫性・流暢性・整合性など）であれば直接適用可能
				* しかし、多くの構成概念は潜在変数であるので、他の観測変数との関係から調べる必要がある
				* 3 つの側面
					* 収束的妥当性 (**Convergent Validity**): 同じ構成概念を測る指標が実際に関連性を持っているかどうか。同一の観点についての異なる手法で得られたスコアには強い相関があるはず
					* 弁別的妥当性 (**Divergent Validity**): 無関係な構成概念を測定する指標が実際に無関係であるかどうか。異なる構成概念についてのスコアは相対的に相関が低いはず（もしそうでなければ評価者の主観などのバイアスが考えられる）
					* 因子妥当性 (**Factorial Validity**): 観測された尺度スコアが、スコアの背後の未観測因子に関する理論と整合しているか。複数の評価指標におけるスコア間の相関が高いならば、共通の潜在因子が存在する可能性がある
				* 前2つは multitrait-multimethod (MTMM) tableで、最後は因子分析で検証する
					* **multitrait-multimethod (MTMM) table**: 複数の構成概念を複数の異なる評価方法を用いて測定する場合に、観測された評価指標スコアが理論が意図する測定対象と整合しているかどうかを検証する（具体例は表1を参照）
						* 例えば、要約タスクで4つの観点＝特性（一貫性、整合性、流暢性、関連性）に基づいて評価するとき、異なる評価方法間で得られたスコア群が、実際にモデルの4つの異なる評価項目（構成概念）に対する性能特性を適切に反映しているかどうかを検証
					* **因子分析**: 指標の因子的妥当性（観測された指標スコアが、実際には観測されていないより少数の因子を測定していると仮定した場合の概念）を測る
						* 例えば、複数の評価指標から得られたスコア間に高い相関が見られる場合、これは共通の潜在因子が存在し、その影響によってこれらのスコアが連動して変動している可能性
						* 因子分析モデルにおいて、ある評価指標は以下の線形結合関数で表される:$$X_j = f(\lambda_{j1} f_1 + \dots + \lambda_{jK} f_K + U_j)$$ただし、$f_k$ は（generalな）潜在因子、$\lambda_{jk}$ は重み、$U_j$ は独自因子（測定誤差を含む）。
							* $f(\cdot)$は、観測スコアが正規分布なら恒等関数、5 段階評価などの順序尺度・歪度が大きい尺度ならステップ関数（順序因子モデル）
							* 因子分析の方法は探索的・確認的の2種類。確認的に行うには、ある潜在因子の$\lambda_{jk}s$を0にして、その因子の評価がなかった場合の変動を調べる
						* 因子的妥当性を測ることで以下が解決できる
							* 適合度指標：確認的因子分析において、理論モデルで想定した因子構造が観測データにどの程度適合しているか
							* 因子スコア：NLGモデルが特定の次元において示す因子スコアとは何か？
							* 因子負荷量：特定の因子が観測された評価指標スコアにどの程度影響を与えるか
							* 残差相関：異なる評価指標間で、共通因子では説明できないスコアの変動（残差）が相関している場合、何か追加的な次元が存在するのか
* 実験: 要約の評価指標を対象としたケーススタディ
	* 設定
		* 使用するベンチマークは SummEval（CNN/Daily Mail 上で 17 モデルが生成した 1700 要約に対し、3 名の専門家が Coherence・Consistency・Fluency・Relevance の 4 つの観点を 5 段階で評価したデータ）
		* ルールベース・埋め込みベース・end-to-end・LLM ベースの計 16 種の自動評価指標を検証
			* ROUGE 系, METEOR, CIDEr, BertScore, MoverScore, BLANC, SUPERT, SummaQA, BARTScore, BLEURT, S3, G-Eval-3.5/4 など
		* 多くの指標でスコア分布が歪んでいたため、正規化 $X_j^* = \Phi^{-1}\!\left(\frac{1}{N}\sum_i \mathcal{I}(X_{ij} \le X_j)\right)$ を行っている
	* 信頼性（安定性と一貫性）：![](https://static.zenn.studio/user-upload/bffcdae714fc-20260902.png)
		* 安定性について、大半の指標は高いが、非決定的アルゴリズムをもつ G-Eval は低かった。同じ G-Eval でも GPT-4 版は GPT-3.5 版より安定していた。![](https://static.zenn.studio/user-upload/af46ba458b22-20260902.png)
		* ROUGE 系では n-gram 長が長くなるほど一貫性が低下した＝データ点の選び方の影響を受けやすい
		* $\sigma_E = \sigma_X\sqrt{1 - \rho_{XT}^2}$ から標準測定誤差を見積もることができる。例えばMETEOR ではモデル間スコアの標準偏差 $.38$、一貫性 $.966$ から $\sigma_E \approx .07$ となり、2つのモデルの間でのスコアの差がこれ未満であれば測定誤差の範囲内とみなせる
	* 構成概念妥当性：
		* 専門家 3 名 × 4 次元の MTMM 表を見ると、![](https://static.zenn.studio/user-upload/50c8b7972d66-20260902.png)
			* 収束的妥当性＝同一次元・異なる評価者間の一致: Kendall の $\tau$ で測ると概ね高かった（$.40$–$.81$）が Fluency では低め
			* 弁別的妥当性: 同一評価者内での Coherence と Relevance の相関（$.65$–$.71$）が、次元をまたがない評価者間相関（$.69$–$.81$）に迫るほど高く、問題
		* 確認的因子分析を行い、統合的妥当性を検証
			* 4因子モデル自体の適合度は良好（Comparative Fit Index $=.999$、Tucker-Lewis Index $=.999$、Root Mean Square Error of Approximation $=.047<0.5$）
			* 因子間相関を推定すると、Coherence–Relevance で $.86$ と高く、両次元が定義上は別物であるにもかかわらず実際には混同されて評価されている可能性
				* 次元の定義の見直し・アノテーションのガイドラインの再検討・テストセットの検査を行うことが可能性としてある、それでも不十分なら要約品質の概念化自体の再考が必要
	* 併存的妥当性：各自動評価指標と、専門家による評価から推定した 4 次元の因子スコア（生の平均値ではない）との Kendall の $\tau$ を調べた![](https://static.zenn.studio/user-upload/737db1510cf0-20260902.png)
		* BARTScore と G-Eval は 4 次元すべてに対して高い相関を示したが、逆に他の次元とも高い相関になってしまったことが課題
			* 例えば Coherence 用に設計された G-EVAL-4-COH は Fluency・Relevance との相関がいずれも $.75$ で、本来の対象である Coherence との相関 $.65$ を上回る
		* SummaQA は Consistency にのみ反応しており、専門家評価との相関は G-EVAL-4-CON にわずかに劣るものの、Consistency 用の指標としてはより望ましい
* 限界
	* 指標の評価は一度だけではなく継続的に行うべき
	* 測定誤差はベンチマーク設計やデータ収集などあらゆる段階で生じうるが、ここでは指標だけしか調べられていない
		* この研究ではベンチマークとしてCNN/Daily Mailのみを用いており、一般化の可能性は不明
	* 教育・心理測定で重視される予測的妥当性（predictive validity）を扱っていない
